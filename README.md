# Sales Data Analysis Using Python

## About the Project

This is my fourth task at Veda Technology. In this project, I analyzed a collection of sales values using Python.

## Objective

To calculate total sales, average sales, highest sale, and lowest sale.

## Tools Used

* Python
* Jupyter Notebook

## Sales Data

I used five sample sales values:

1200, 2500, 1800, 3000, 2200

## Results

* Total Sales: 10700
* Average Sales: 2140
* Highest Sale: 3000
* Lowest Sale: 1200

## What I Learned

Through this task, I learned how to use Python's `sum()`, `max()`, and `min()` functions and calculate average sales.

## Conclusion

This project helped me understand the basics of numerical data analysis using Python.
